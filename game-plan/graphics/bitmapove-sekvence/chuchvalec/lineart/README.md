# Zkouška inkoustových obrysů

Jeden návrh Chuchvalce pro následné vybarvení, vytvořený vestavěným imagegen. Zadání je v `prompt.txt`, výstup v `chuchvalec-ink.png`. Obrysy, černé záhyby a tmavé dutiny; brusle místo běžné podrážky. Návrh není schválený.

Generátor nedodržel technické zadání: skutečný výstup je 1122 × 1402 px RGB, bez alfa kanálu; šachovnice je součástí obrázku. Nejde o průhledný finální sprite 384 × 480. Výstup nebyl zmenšen, ořezán ani vložen místo aktuální animace. Před použitím v Cadmium je potřeba opravit podklad a připravit odpovídající snímky.

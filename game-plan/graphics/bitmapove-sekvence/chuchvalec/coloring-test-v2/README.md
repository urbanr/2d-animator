# Chuchvalec — srovnání vybarvení

- `frames/`: osm černobílých kreseb 384 × 480 px se skutečným průhledným pozadím.
- `reference-00.png`: barevný vzor odpovídající přesně obrysům prvního snímku.
- `preview-black.png`: kontrolní náhled osmi kreseb na černém pozadí.
- `reference-00-black-preview.png`: kontrolní náhled barevného vzoru na černém pozadí.
- `palette.json`: pevné barvy použité ve vzoru.
- `source/`: zdrojový list na černém pozadí, zadání a reprodukovatelné zpracování.

Barevný vzor vznikl ve dvou krocích: generovaný barevný průvodce určil materiály a následný paint-bucket převod je vložil do uzavřených oblastí původní černobílé kresby. Výsledkem jsou původní obrysy, souvislé barvy pod černou linkou a žádná přidaná stínovací vrstva. Sada je návrh k porovnání v Cadmiu, nikoli schválená finální animace.
